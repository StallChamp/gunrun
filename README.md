# gunrun test builds

Playtest builds of gunrun. Download the zip for your system, unzip, run.

| System | Download | Run |
|---|---|---|
| Windows | [gunrun-windows.zip](../../raw/main/gunrun-windows.zip) | unzip, double-click `gunrun.exe` (if SmartScreen warns: More info → Run anyway) |
| Linux | [gunrun-linux.zip](../../raw/main/gunrun-linux.zip) | unzip, `chmod +x gunrun.x86_64`, run it |

Built 2026-10-13 from `1e29203` (feature/procedural-animation).

## Controls

F1 opens the tuning panel. H switches the camera between the head and the old fixed view.
